# 峰值占用解释

`explain PROBLEM.json [LAYOUT.json]` 输出每个内存区最早达到最大活跃字节数的时间步、当时存活的缓冲区 ID／大小／偏移，以及布局超预算量与活跃字节超预算量。省略布局时使用贪心计划；提供布局时先独立核验结构约束。退出码 0 为当前布局满足容量，1 为超预算，2 为输入或布局结构错误。

highwater_minus_peak 是布局高水位与峰值活跃字节数的差，包含固定空洞、对齐等影响，不能全部称为碎片。live_over_budget_by 仅描述当前 bank 分配；在允许切换 bank 的问题中，它不证明所有方案都不可行。

exact_alignment.json 的贪心高水位是 12，活跃峰值为 9，容量为 9，报告分别给出布局超出 3、活跃字节超出 0。结合 exact 模式，使用者可进一步确认能否重新布局。budget_failure.json 在交接步明确列出 input 和 output，避免只报告抽象的容量数值。
