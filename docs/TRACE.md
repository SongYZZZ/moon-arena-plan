# C 运行轨迹到静态生命周期

trace TRACE.json 读取 schema 1 的完整逻辑使用轨迹：banks、buffers（ID、字节数、对齐、允许 bank、可选固定位置）、events（step、op、buffer）。支持 begin/read/write/end，时间步非递减且两端包含，每个 ID 对应一个闭合生命周期。重复开始、未开始／结束后的读写、未知 ID、缺少结束和未观测到的声明对象均拒绝。最多 2048 个对象、65536 个事件，时间步 0..1000000。

examples/trace_capture 是执行数组变换并在调用点记录事件的 C 例程，输出 JSON。经过 trace 命令导入后，a／b／c 的生命周期分别为 [0,1]、[1,2]、[2,3]，生成 48 字节布局；该布局再导出头文件并用于 C replay 检查数据保持。

这是逻辑调用点追踪，需要调用方准确记录所有相关读写和持久占用。工具检查已记录轨迹，不自动拦截任意指针访问，不证明其他输入、未记录路径或异步硬件时序安全；重复分配同一对象应提供不同 ID。本示例不是实际神经网络或板卡部署。
